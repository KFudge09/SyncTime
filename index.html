How to Host Completely Free

You can host this entire web application for $0/month forever using GitHub Pages, Netlify, or Vercel combined with Firebase's free tier!

Option 1: GitHub Pages (Easiest)

  1. Create a free repository on GitHub (e.g. timetable-share).
  2. Upload this index.html file directly into the repository.
  3. Go to Settings > Pages in your GitHub repo and select main branch.
  4. Your app will be published instantly at https://yourusername.github.io/timetable-share.

Option 2: Netlify / Vercel Drop

  1. Go to app.netlify.com/drop or Vercel dashboard.
  2. Drag and drop the folder containing index.html.
  3. You will immediately get a shareable live HTTPS URL for free!
